# PC 本地控制台

这个目录包含独立 PC 控制台。它与 ASR 服务使用不同进程、不同端口：控制台默认 `http://127.0.0.1:8766`，ASR 默认 `8765`。控制台不导入模型、不采集电脑麦克风，也不保存录音。具体启动方式见项目根 README 与本目录启动脚本。

前端从自己的 `/api/console` 读取 ASR WebSocket 地址、设备 ID 与本机配对信息。WebSocket 地址以 API 返回值为准，不会把浏览器的 8766 误当成 ASR 端口。

## 功能

- 实时录音状态、音量、分句字幕、历史与复制；BOOT 按住录音、松开结束。
- 上次录音时长、首个临时字幕耗时、松键后最终完成时间；计时字段缺失时显示“—”。
- 字幕以录音/分句/revision 归并，最终结果覆盖临时结果；延迟情绪只补对应句子。
- 已完成分句可以打开“校对文字”，原始识别始终独立保留，当前显示版和原文可以分别查看/复制。校对最多 512 个 Unicode 字、1536 UTF-8 字节，禁止 TAB 和控制符，仅保留正常换行；`null` 才表示恢复原始识别。
- 保存校对等待服务端落盘确认，**不会自动推送 OLED**。保存后可分别选择“推送校对后”或“推送原始识别”；只有设备 ACK 后才报告屏幕已更新。录音/识别期间禁用历史推送，旧固件未声明能力时保留校对功能并提示升级。
- 校对版本独立于 ASR 修订号。另一端修改造成冲突时，输入草稿保留，显示最新已保存版本，用户显式选择“基于最新版本继续编辑”后才能再次保存。校对、推送和屏幕设置使用独立 pending 状态，切换连接/隐藏页面不会把未确认操作冒充成功。
- OLED 字号 1～4 倍、分页/上滚/逐字/静态、翻页停留、滚动速度、亮度、动画；待收到开发板实际 ACK 才报告已应用。草稿与当前实际值分离。
- 选择电脑局域网地址，显示供小程序扫描的二维码；可以复制地址或完整配对 JSON。口令默认隐藏，不写入浏览器 localStorage。
- 句子情绪标签来自 SenseVoice 声学模型；独立的文本词语规则用于高亮情绪线索，详情说明否定和程度。规则高亮不是词级声学预测，不会把否定词直接变成相反的真实情绪。
- 当前缓存的情绪分布只统计已有模型情绪标签的句子，排除 unknown、跳过和失败。
- 可选音频质量说明来自情绪进程：主视图只提示片段较短、声音可能过载或长句部分分析；具体时长、峰值、RMS 和削波比例放在展开详情。这些测量不是情绪置信度。
- 可选参考候选仅在详情中展示，最多 3 个，标明是模型未校准的原始分数；不用百分比，不覆盖主标签，不纳入情绪分布。模型返回 `unknown` 时仍如实显示未识别。

## 性能与边界

无框架、无 CDN、无网络字体。与小程序共用有界协议归并器：最多 160 个分句、64K UTF-16 总文字（原始识别和校对文字共同计入）。实时消息最多每 80 ms 合并一次 DOM 更新；未变化的分句不会重建节点，文本高亮每句最多 16 处，全部字幕通过 textContent/文本节点插入，避免将识别结果当成 HTML。

页面隐藏时关闭 WebSocket、暂停健康轮询和渲染；回来后重连补齐快照。主动暂停同步后，切换标签页不会擅自恢复。连接使用有界退避和心跳，瞬间 open/close 不重置退避；慢消费者不能积压不受控的发送队列。配对二维码由独立控制台的本机 API 生成，不将 token 放进二维码请求 URL。

## 前端验证

本目录无需安装 npm 依赖：

```powershell
npm test
```

测试覆盖浏览器/CommonJS 共享协议、独立端口、真实 ACK、重连与前后台生命周期、延迟情绪、模型统计分母、Unicode 与恶意文本、高亮范围上限，以及长字幕资源预算。

Node 测试不代替实际浏览器与开发板验收。浏览器检查应至少覆盖桌面和 375px 宽度、键盘输入、断线恢复、真实设备设置 ACK 和小程序扫码配对。
